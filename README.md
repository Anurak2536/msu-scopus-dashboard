# Executive PUBLICATIONS SCOPUS — มหาวิทยาลัยมหาสารคาม

Dashboard วิเคราะห์ผลงานตีพิมพ์ในฐานข้อมูล Scopus ของมหาวิทยาลัยมหาสารคาม
จัดกลุ่มวารสารตาม Percentile (Tier1 / Q1–Q4) และเชื่อมโยงกับทะเบียนนักวิจัยเพื่อแยกตามคณะ

**🔗 เปิดใช้งาน:** https://anurak2536.github.io/msu-scopus-dashboard/

## ข้อมูลในระบบ

| รายการ | จำนวน |
|---|---|
| ผลงานตีพิมพ์ | 8,871 รายการ (ปี 1994–2026) |
| นักวิจัย (จาก Scopus) | 15,718 คน |
| ทะเบียนบุคลากร มมส. | 780 คน / 22 คณะ |
| วารสารพร้อม Percentile | 1,567 รายการ |

## หน้าจอ

- **ผลงานตีพิมพ์** — ภาพรวม, แนวโน้มรายปี, แยกตามคณะ, รายการผลงานทั้งหมด
- **วารสาร** — จำแนกตาม Quartile และการอ้างอิง
- **สำนักพิมพ์** — จำนวนผลงานแยกตามสำนักพิมพ์
- **เครือข่ายความร่วมมือ** — แผนที่โลกแสดงประเทศผู้ร่วมวิจัย
- **นักวิจัย** — ข้อมูลรายบุคคล, h-index, Documents & Citations รายปี

ทุกหน้าใช้ตัวกรองปีร่วมกัน (ทุกปี / ปีเดียว / ช่วงปี)

## การอัปเดตข้อมูล

ข้อมูลชุดปัจจุบันฝังอยู่ในไฟล์ `index.html` แล้ว เปิดใช้งานได้ทันทีโดยไม่ต้องอัปโหลด

หากต้องการอัปเดต ให้ไปที่หน้า **"อัปโหลดข้อมูล"** แล้วอัปโหลด 2 ไฟล์:

| ช่อง | ไฟล์ | คอลัมน์ที่ต้องมี |
|---|---|---|
| ไฟล์วารสาร | `jurnal.xlsx` (ชีต `ข้อมูลวารสาร`) | `ชื่อวารสาร`, `ISSN`, `Percentile` |
| ไฟล์ Scopus | Scopus export **แบบรายรายการ** (.xlsx) | `Authors`, `Title`, `Year`, `Source title`, `ISSN`, `Document Type`, `Author(s) ID`, `Authors with affiliations`, `Cited by`, `Link`, `Publisher` |

> ⚠️ ต้องใช้ Scopus export **แบบรายรายการ** เท่านั้น
> ไฟล์สรุปจากหน้า *Analyze results* (เช่น `Scopus-Analyze-Country.csv` ที่มีแค่ชื่อประเทศกับจำนวน) ใช้ไม่ได้
> และปัจจุบันระบบยังรับเฉพาะ `.xlsx` / `.xls` — หาก export มาเป็น CSV ต้องแปลงเป็น .xlsx ก่อน

ข้อมูลที่อัปโหลดจะถูกบันทึกไว้ใน IndexedDB ของเบราว์เซอร์ผู้ใช้เท่านั้น (ไม่ส่งขึ้นเซิร์ฟเวอร์)
กดปุ่ม **"กลับไปใช้ข้อมูลปัจจุบัน"** เพื่อล้างและกลับไปใช้ชุดข้อมูลที่ฝังมากับไฟล์

## เทคนิค

ไฟล์ HTML เดี่ยว ไม่มี build step — ดับเบิลคลิกเปิดจากเครื่องก็ใช้งานได้
เรียกไลบรารีจาก CDN: [SheetJS](https://sheetjs.com/) 0.18.5, [D3](https://d3js.org/) 7.9, topojson-client 3.1

## หมายเหตุด้านข้อมูล

- การจับคู่วารสารใช้ ISSN เป็นหลัก ผลงานที่หา ISSN ไม่ตรงจะแสดงเป็น *"ไม่พบวารสารในรายการ (ISSN ไม่ตรง)"*
- ประเทศของผู้ร่วมวิจัยได้จากการแกะคอลัมน์ `Authors with affiliations` ตรวจสอบเทียบกับรายงาน Scopus Analyze by Country ปี 2026 แล้วตรงกัน 97–100%
